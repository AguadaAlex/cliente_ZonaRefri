## 🚀 Sobre el Proyecto
**Zona Refri** es un sistema full-stack desarrollado como proyecto integrador. Su objetivo principal es ofrecer una experiencia de usuario fluida para la búsqueda, visualización y gestión de productos del hogar, integrando un catálogo persistente y gestión de imágenes en la nube.

---

## 🛠️ Tecnologías Utilizadas

### **Backend**
*   **Java 17 / Spring Boot:** Arquitectura RESTful y lógica de negocio.
*   **Spring Data JPA / Hibernate:** Gestión de persistencia y mapeo objeto-relacional.
*   **Base de Datos H2:** Base de datos en memoria optimizada para desarrollo e inicialización automática.
*   **Cloudinary API:** Almacenamiento y gestión de imágenes multimedia en la nube de forma segura.

### **Frontend**
*   **React (Vite):** Interfaz de usuario dinámica, moderna y responsiva.
*   **JavaScript / HTML5 / CSS3:** Estructura y diseño visual de componentes.

---

## 🌟 Características Principales
*   **Catálogo Permanente Automático (`DataInitializer`):** Carga inicial automatizada de productos estructurados (heladeras, cocinas, microondas, climatización) para evitar datos vacíos al reiniciar el servidor.
*   **Gestión de Imágenes en Cloudinary:** Enlaces optimizados y centralizados para asegurar la disponibilidad visual de los artículos.
*   **Estructura Modular:** Controladores, servicios, repositorios y entidades bien definidos bajo buenas prácticas de desarrollo en capas.
