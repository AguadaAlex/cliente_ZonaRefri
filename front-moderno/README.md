## 🚀 Sobre el Proyecto
**Zona Refri** es un sistema full-stack desarrollado como proyecto integrador. Nuestra plataforma no solo facilita la compra de productos, sino que también funciona como un **centro de servicios de reparación técnica especializada** para electrodomésticos, brindando soluciones integrales de mantenimiento y venta en un solo lugar.

---

## 🛠️ Tecnologías Utilizadas

### **Backend**
*   **Java 17 / Spring Boot:** Arquitectura RESTful y lógica de negocio.
*   **Spring Data JPA / Hibernate:** Gestión de persistencia y mapeo objeto-relacional.
*   **Base de Datos H2:** Base de datos en memoria optimizada para desarrollo e inicialización automática.
*   **Cloudinary API:** Almacenamiento y gestión de imágenes multimedia en la nube de forma segura.

### **Frontend**
*   **React (Vite):** Interfaz de usuario dinámica, moderna y responsiva.
*   **JavaScript / HTML5 / CSS3:** Estructura y diseño visual de componentes.

---

## 🌟 Características Principales
*   **Servicio de Reparación Integral:** Gestión de solicitudes de mantenimiento y reparación técnica para equipos de climatización y electrodomésticos.
*   **Catálogo Permanente Automático (`DataInitializer`):** Carga inicial automatizada de productos y servicios para asegurar una experiencia de usuario completa desde el primer acceso.
*   **Gestión de Imágenes en Cloudinary:** Enlaces optimizados para la visualización de productos y reportes de estado de equipos.
*   **Estructura Modular:** Controladores y servicios definidos bajo buenas prácticas para separar la lógica de venta de la lógica de reparación.
